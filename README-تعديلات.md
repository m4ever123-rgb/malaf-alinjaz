# النسخة المعدلة — منصة ملف الإنجاز

هذه نسخة مستقلة مُعاد بناؤها من النسخة المنشورة في الرابط المرسل، مع الحفاظ على التطبيق الأصلي وتعديل طبقة التقارير فقط.

## التعديلات
- تقرير الأداء الوظيفي وفق بنود الصورة المرفقة، مع 11 محوراً وأوزان 10% و5%.
- عرض جميع المؤشرات الفرعية داخل التقرير.
- تقرير الأداء في صفحة A4 أفقية واحدة بدون غلاف.
- إخفاء الأغلفة من التقارير المولدة مع الإبقاء على الترويسة والتذييل.
- تحديث المعايير المحفوظة تلقائياً عند فتح نسخة قديمة.
- الحفاظ على IndexedDB، النسخ الاحتياطي، الشواهد، التقارير، القوالب، التخصيص والطباعة والتصدير.

## التشغيل
يمكن فتح `index.html` مباشرة، أو تشغيل خادم ثابت من هذا المجلد:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```
